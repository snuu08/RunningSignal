# 강남 데모 파일럿

파일럿 ID: `gangnam-exit1-kukkiwon-v1`

목표: 같은 출발지와 목적지에서 “노래가 끊기는 길”과 “리듬이 이어지는 길”을 짧은 영상으로 비교한다.

## 검증된 것

- 출발지: 강남역 2호선 1번출구.
- 목적지: 국기원.
- TMAP 보행 route 생성 성공.
- 거리: 626m.
- 횡단 후보: `쿡앤쑈에서 좌측 횡단보도`, route 약 214m 지점.

## 아직 검증 안 된 것

- 보행신호 group.
- 교차로 ID.
- 운영계획.
- epoch.
- 초록불 도착 여부.

## 해결 방법

현재 서비스에서 거짓 예측을 켜지 않는다. 대신 강남 route와 현장조사 파일을 만들었다.

현장 촬영에서 실제로 멈추지 않는 시간대를 찾고, 그 관측을 `field-observation.csv`에 넣는다. 그 뒤 fixed plan과 epoch를 확인할 때만 prediction scope 후보로 올린다.

## 영상 문장

같은 목적지. 같은 노래. 카카오맵은 가까운 길. Flow Run은 리듬이 끊기지 않는 길을 찾는다.

## 금지 문장

현장 검증 전에는 “Flow Run이 실제 강남 신호를 예측한다”라고 말하지 않는다.
