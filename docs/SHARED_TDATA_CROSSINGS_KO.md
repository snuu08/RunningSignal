# 서버 공통 호출 제한과 실제 횡단보도 대조

운영 Netlify Function은 `@netlify/database`의 Postgres를 사용합니다. 패키지를 포함한 배포에서 DB가 자동 준비되고, `netlify/database/migrations/`의 SQL이 적용됩니다. 연결 문자열은 플랫폼이 주입하며 소스나 브라우저에 포함하지 않습니다. DB 사용량은 기존 Netlify 크레딧을 사용합니다.

## 호출 제한

- 계정 행을 트랜잭션으로 잠근 뒤 호출 권한을 예약합니다. 여러 인스턴스와 교차로가 같은 예약·대기시간을 공유합니다.
- 현재 전용 API는 서비스별 최소 2초, 과거 현시·잔여시간 및 MAP API는 보수적으로 최소 5분 간격을 적용합니다. 같은 요청은 공유 캐시를 재사용합니다. 이 간격은 앱의 정책이며 제공기관의 모든 한도를 확정한 값이 아닙니다.
- 명시적으로 서비스가 지정된 429만 서비스별로 차단합니다. 그 외 429는 계정 전체를 차단합니다. 제공기관의 `Retry-After`가 더 길면 그 값을 따릅니다. 차단 중에는 이전 성공 캐시도 반환하지 않습니다.
- 호출 전 예약을 커밋해 작업 중단 뒤 즉시 같은 호출을 반복하지 못하게 합니다. 30초 임대와 호출별 토큰으로 늦은 완료가 다른 작업의 캐시를 덮어쓰지 못하게 합니다. 제공기관 요청은 6초 제한입니다.
- DB 연결·저장 실패 때는 제공기관을 추가 호출하지 않습니다. 미리보기와 공개되지 않은 배포도 운영 키로 실시간 호출하지 않습니다.
- 응답 `coordination`의 `instanceId`, `callId`, `source`로 다른 인스턴스의 공유 캐시 사용을 확인할 수 있습니다. 키·사용자 위치는 이 저장소에 넣지 않습니다.

범위는 이 앱의 새 서버 배포입니다. 같은 제공기관 계정을 사용하는 다른 앱이나 사람이 직접 보낸 요청은 이 예약에 참여하지 않습니다. 제공기관의 실제 한도와 정책을 변경하거나 우회하지 않습니다.

## 실제 횡단보도

개발 연결 확인 화면은 공식 자료의 횡단보도 관리번호·보행등 설치 여부·2026년 위치와 2021년 도형을 표시합니다. 국기원입구, 국기원입구(연등), 망원역(연등)의 후보 13개를 포함합니다. 출처·원본 SHA-256·좌표계 근거는 카탈로그에 기록합니다.

T-GIS 교차로 관리번호와 T-DATA 교차로 ID는 서로 다른 체계입니다. 같은 이름은 후보를 찾는 근거이며, 신호 필드 대응을 확정하지 않습니다. 오래된 도형은 현재 양끝점의 증거로 자동 승격하지 않습니다.

휴대폰에서 실제 횡단보도와 보행 필드를 선택하고, 안전한 인도에서 진입·도착점 GPS를 기록합니다. 직접 본 보행등 상태를 선택한 시점과 최신 API 응답을 함께 기록합니다. 각 적색·녹색 전환 2회 이상, 동일 장비, 원천 시각 오차 5초 이내, GPS 정확도 10m 이내, 잔여값 단위를 검토합니다. 관측은 같은 30분 현장 검사에 속해야 합니다.

정확한 위치와 관측 기록은 해당 기기에만 저장하며 JSON으로 내려받을 수 있습니다. JSON에는 정확한 위치가 포함됩니다. 제출이나 외부 전송은 자동으로 하지 않습니다. 검토자료가 충분해도 `physicalCrossingVerified`와 `predictionReady`는 계속 `false`입니다. 관리번호·실제 양끝점·보행 필드·중간 안전지대별 단계 대응을 검토한 뒤 검증 번들에 반영해야 합니다.

## 검증

`npm test`는 공유 DB의 실제 SQL, 독립 클라이언트의 캐시 재사용, 429 범위, 작업 중단, 만료 토큰, 비밀정보 제거, DB 실패 차단, 원천 시각 유지 및 현장 기록 조건을 확인합니다. SQL 테스트의 PGlite는 단일 연결 엔진이므로 운영 서버의 부하 테스트를 대체하지 않습니다.

`npm run verify:release -- https://your-site.example [intersectionId]`는 배포 버전·공유 DB 사용·실제 최신 신호 수신을 확인합니다. 현장 검사를 수행한 것으로 간주하지 않습니다.
