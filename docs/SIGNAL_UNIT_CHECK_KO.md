# 보행 잔여값 단위 측정

개발 연결 확인 화면에서 교차로 ID를 입력하고 `단위 측정 시작`을 누른다.
현재 전용 통합 응답을 최대 8회 조회하며, 각 응답 이후 5초를 기다린다.
화면을 숨기거나 측정을 중단하거나 다른 화면으로 이동하면 요청과 타이머를 정리한다.
요청 시간 초과나 오류가 발생하면 자동 반복을 중단한다.
제공기관이 재시도 대기시간을 반환하면 교차로를 바꿔도 그 대기를 유지한다.

원천 시각이 최신이고 보행 상태·잔여값이 함께 있는 응답만 사용한다.
교차로·장비·원천 시각이 일치하는 단일 패킷을 확인한다.
상태가 바뀌거나 교차로·장비가 달라지는 두 표본은 비교하지 않는다.
같은 패킷의 반복 수신이나 2초 미만·30초 초과 원천 간격도 비교하지 않는다.

동일 상태에서 원천 시각 차이와 잔여 원시값 감소량을 비교한다.
최소 4쌍, 합계 20초 이상의 관측 구간이 필요하며 모든 비교 구간이 일치해야 한다.
감소율이 초당 10±1이면 1/10초, 100±10이면 1/100초라는 측정 결과를 표시한다.
고정된 카운트다운·초기화·상이한 감소율은 미확인으로 남긴다.
이는 표본에 근거한 단위 측정이며 제공기관의 일반 단위 보장이나 현장 정확도 인증이 아니다.

`측정 JSON 내려받기`는 표본·원천 시각·장비·필드별 결과를 기기에 저장한다.
이 결과는 물리적인 횡단보도와 보행등 필드의 대응을 확인하지 않는다.
횡단 양끝점·진행 방향, 실제 보행등과의 대응, 잔여값 종료 의미 및 경로 누락 여부는 별도로 검증한다.
검증된 매핑과 보행 녹색 지속시간을 임의로 생성하거나 공개 예측을 자동 활성화하지 않는다.

현재 상태 패널의 원천 경과시간은 화면에서도 계속 증가한다.
10초를 넘긴 응답은 새 요청이 없어도 현재 관측 만료로 표시한다.

재호출 공유와 제한은 기존처럼 서버 인스턴스 내부에 한정된다.
여러 서버 사이의 원자적 공유 제한은 별도 구현이 필요하다.

테스트에는 두 단위의 구분, HTTP 지연과 원천 시각의 분리, 반복 패킷·다른 장비·상태 전환·초기화 거절,
8회 조회 상한, 취소·숨김 화면의 정리, 교차로 변경 후 재시도 대기 및 화면 관측 만료가 포함된다.
